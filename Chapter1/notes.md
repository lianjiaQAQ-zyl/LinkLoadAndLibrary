# 第一章 温故而知新

## 1.2 万变不离其宗

1. 由于 CPU 核心频率的提升，导致内存跟不上 CPU 的速度，所以产生了与内存频率一致的系统总线，CPU 采用**倍频**的方式与系统总线进行通信。

   > Intel Core i7-14700K: 最高 5.6 GHz
   >
   > 这里的 GHz 指的是 CPU 核心时钟频率（Core Clock Frequency），它通常来自一个更低的基础时钟。
   >
   > CPU 频率 = 外频 * 倍频，外频指的是外部时钟频率，可以理解为与外部设备通信的频率，现在更多使用 BLCK，Base Clock这个词，难以直接提高，所以通过倍频的手段。
   >
   > 现代 CPU 中，会结合 Turbo Boost/Precision Boost 会通过调整倍频实现动态频率控制。

2. 北桥连接高速设备，南桥连接低速设备。

   > **传统意义上的南桥和北桥现在基本已经不存在了。**
   >
   > 北桥的大部分功能已经被集成进 CPU；南桥的功能则演化成了 **PCH（Platform Controller Hub，平台控制器中心）** 或类似的 I/O 控制芯片。

## 1.3 站得高，望得远

1. 应用程序通常通过运行库（Glibc 提供的 Posix API，Windows API）等提供的 API 使用系统功能。运行库在需要内核服务时，通过系统调用接口请求操作系统完成相应操作。系统调用通过特定的指令从用户态进入内核态，具体机制取决于处理器架构和操作系统，例如软中断指令或专用的系统调用指令。

## 1.4 操作系统做什么
1. 向上：提供接口
   向下：管理硬件资源
2. 在 `unix` 系统中，设备抽象成文件；在 `windows` 系统中，图形硬件被抽象成 GDI，声音和多媒体设备抽象为 DirectX 对象，磁盘抽象成文件系统。
3. 硬盘的基本存储单位是扇区，每一个扇区一般是 512 个字节。
