# 第二章 编译和链接
### 2.1 被隐藏了的过程
1. 预编译 -> 编译 -> 汇编 -> 链接。（以 `gcc hello.c` 为例）
	- 预编译：使用预编译器 `cpp` 生成 `.i` 文件。预编译过程中将`#define` 删除，展开宏定义；处理所有的条件预编译指令，比如`#include` `#if` ；删除注释；添加行号和文件标识；保留编译器指令，如 `#pragma` 
	- 编译：将预处理好的文件进行词法分析、语法分析、语义分析以及优化后生成相应的汇编代码文件。
	- 汇编：将汇编代码转变为机器可以执行的指令。
	- 链接：将不同的目标文件组合起来，生成最终的可执行文件。

2. `hello.i` 中  `#` 开头的行叫**行标记**（line markers），是预处理器给编译器的位置信息。然后是文件路径，最后是标记位，1 表示进入一个被包含的文件，2 表示从一个被包含的文件返回包含它的文件，3 表示来自系统头文件，4 表示告诉 C++ 编译器按 C 语言链接规则处理相关声明，便于调用 C 库函数。

3. 对于 `.o` 文件（可重定位目标文件），可以使用 `objdump` 进行查看。`-r` 选项可以查看重定位信息。
